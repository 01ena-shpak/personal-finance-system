## 3. Ризики та залишкові зауваження

- Redocly warnings про відсутню `info.license` і локальний `localhost` не впливають на коректність контракту.
- TestClient має deprecation warning; поточні 160 tests стабільно проходять, але залежність слід оновити в окремій задачі.
- `uvicorn[standard]==0.54.0` зафіксовано в `requirements.txt` за фактично встановленою сумісною версією; передумову відтворюваного запуску REST API закрито.
- Скриншоти ручної Validation збережені локально й ще мають бути додані до звіту.
- Flet-клієнт навмисно не реалізований у лабораторній №5; його не можна вважати виконаним за результатами цього Gate.
- GitHub-статуси тікетів можуть не відображати фактичну готовність REST-частини; це адміністративне, а не функціональне відхилення.

Блокувальних дефектів REST API не виявлено. Контроль SQLite/rollback, точності сум, посилальної цілісності, безпечного тексту та людського Gate-рішення виконано відповідно до релевантних ризиків `R-05`–`R-08`, `AI-03`, `AI-05`, `AI-06`.
