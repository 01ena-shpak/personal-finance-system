# Coding Agent

## Agent

OpenAI Codex

## Tool Class

AI coding agent.

## Repository Access

Codex is used as an extension in Visual Studio Code in Local mode. It works directly with the files of the currently opened local Git repository.

## Available Operations

The agent can:
- analyze the project structure;
- read project files;
- create and modify files;
- assist with writing source code;
- execute commands in the working environment.

All changes made by the agent are reviewed by the student before being accepted and committed to the repository.
