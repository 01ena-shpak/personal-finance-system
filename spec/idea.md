# Initial System Idea

## Topic

Information system for personal income and expense tracking.

## Purpose

The information system is intended for keeping track of a user's personal finances. The system allows the user to add and store information about income and expenses, view financial transactions, and determine the current balance.

## Main User

The main user is an individual who wants to keep track of their personal income and expenses.

## Problem

The system addresses the problem of inconvenient manual tracking of personal financial transactions and makes it easier to understand the user's current financial balance.

## Basic Rule

The current balance is calculated as total income minus total expenses.
